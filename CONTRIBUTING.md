# Contributing to CleanText

Thanks for your interest in improving CleanText!

## Before you start

- Check existing issues before opening a new one.
- For larger changes, open an issue first to discuss the idea.
- Keep the app usable without a build step or package installation unless a change clearly requires otherwise.

## Changes

1. Fork the repository and create a focused branch.
2. Make a small, clearly scoped change.
3. Test `index.html` in a modern browser.
4. Check the browser console for errors.
5. Update the README or docs if behavior changes.
6. Open a pull request explaining what changed and how you tested it.

Please be respectful and constructive in discussions.
